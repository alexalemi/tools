CRC-16 Short Code

A CRC-16 of any text, truncated to 10 bits and rendered as a 2-character code that avoids look-alike letters.

Encoding

The text is encoded as UTF-8 and run through the selected CRC-16. The low 10 bits of the result (0–1023) are written in base using this alphabet, zero-padded to 2 characters:

Dropped: I, L, O (confusable with 1 and 0). Comparison is case-insensitive and maps i/l→1, o→0, so a misread code still matches.
