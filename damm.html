Damm Check Digit

Compute or verify a Damm check digit for any string of digits.

Non-digit characters (spaces, dashes) are ignored.

How it works

Start with an interim digit of 0. For each input digit d, replace the interim with table[interim][d]. The final interim is the check digit. A number that already ends with its check digit folds to exactly 0, because the table's diagonal is all zeros.

Damm detects all single-digit errors and all adjacent transpositions, with no special case for digits like "X" in ISBN-10.

Based on H. Michael Damm's totally anti-symmetric quasigroup (2004)
